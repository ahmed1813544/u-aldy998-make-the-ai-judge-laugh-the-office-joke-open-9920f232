One line of office comedy, written by a tiny deterministic Python program.

## The joke

> I set my Slack status to 'in a meeting' so I could finally do the work from the meeting I was in a meeting about.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one line
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No
network, no randomness — two runs produce byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
